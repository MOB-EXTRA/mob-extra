# Marc Johnford portfolio

This portfolio is included as a standalone, static site inside MOB EXTRA. It keeps its own branding, assets, CSS modules, JavaScript, project data, and legal content.

## Edit the site

- `index.html` is the page served to visitors.
- `assets/css/style.css` imports the focused files in `assets/css/modules/`.
- `assets/js/` contains the portfolio’s separate site behaviors.
- `assets/img/` contains the portfolio imagery and identity assets.
- `works/` contains project metadata, gallery data, and thumbnails.
- `legal/index.html` contains the portfolio policy page.

Edit these files directly. The portfolio is plain HTML, CSS, JavaScript, and JSON, so it does not require Node.js, npm, or a build step. Use any static file preview server to review changes.

The `MOB EXTRA` link in the portfolio header returns visitors to the main site.
