What you’ll find in the MOB EXTRA toolkit

The directory brings together focused utilities for gaming, front-end work, and other digital tasks:

  • Player name formatting: Preview a CODM name with selectable Unicode spacing, then copy it for use in game. The formatter counts all characters toward its 14-character input limit.
  • CSS unit conversion: Convert between pixels and rem, batch-convert CSS values, and generate fluid clamp() rules in the PX ↔ REM converter.
  • Focused, browser-based utilities: Each tool has its own instructions and controls, so you can open the relevant utility directly on desktop or mobile.

Frequently asked questions about MOB EXTRA tools

Are these tools only for mobile players?

No. It includes game-specific utilities and general browser tools such as CSS converters. The pages are designed to work on mobile and desktop.

Will a formatted Unicode name always work in CODM?

Not necessarily. Unicode character support can vary by game update, region, or platform. Check the preview and test the copied name in game before using it permanently.

Can I suggest a tool or report a problem?

Yes. Use the Contact page to suggest a utility or report an issue with an existing tool.
