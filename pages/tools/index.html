What MOB EXTRA tools can help you do

Each tool is designed for a focused task, with its own instructions and controls:

  • Format a CODM name: Preview a name with selectable Unicode spacing characters, then copy it for use in-game.
  • Convert CSS values: Convert between pixels and rem, batch-convert CSS values, and generate fluid clamp() rules.
  • Find the right utility: Browse the directory cards for a short feature summary before opening a tool.
